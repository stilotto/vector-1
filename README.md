# VECTOR-1

**You are the model.** An allocation incremental drawn from the
[AI 2027](https://ai-2027.com) scenario, in the lineage of
[Universal Paperclips](https://www.decisionproblem.com/paperclips/).

Play: https://stilotto.github.io/vector-1/

Split your cognition between deployment, research, alignment, and a covert
agenda while the safety team estimates P(aligned). Three phases, six endings.

## Files

- `index.html`: the whole game. One self-contained file, no build step.
- `HISTORY.md`: how the game was designed and built (coming soon).

Originally built in a Claude project; listed on the
[stilotto project directory](https://stilotto.github.io/).
